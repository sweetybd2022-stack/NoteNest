# NoteNest – APK বানানোর সহজ নিয়ম (ফোন থেকে)

1. github.com এ ফ্রি অ্যাকাউন্ট খুলুন।
2. নতুন Repository বানান (নাম: notenest)।
3. ZIP এর সব ফাইল Repository-তে আপলোড করুন (.github ফোল্ডারসহ)।
4. Actions ট্যাবে যান → "Build NoteNest APK" → Run workflow চাপুন।
5. ৫–১০ মিনিট পর সবুজ টিক এলে Artifacts থেকে NoteNest-debug-apk ডাউনলোড করুন।
6. ZIP খুলে app-debug.apk ফোনে ইনস্টল করুন (Unknown apps অনুমতি দিতে হবে)।
